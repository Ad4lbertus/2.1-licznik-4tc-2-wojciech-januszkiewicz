## Opis aplikacji
Aplikacja to estetyczny i intuicyjny licznik kliknięć z oknem desktopowym.
Zawiera:
- Wyświetlacz aktualnej wartości licznika ze zmianą kolorów (niebieski dla liczb dodatnich, czerwony dla ujemnych, szary dla zera),
- Duży główny przycisk **`+1 KLIKNIJ`**,
- Przycisk pomocniczy **`-1 Odejmij`**,
- Przycisk zerowania **`↺ Zeruj (Reset)`**,
- Pasek stanu z informacją o ostatniej wykonanej akcji i łącznej sumie kliknięć.

---

## Jak uruchomić aplikację?

### 1. Wersja Desktopowa (Windows)
- Uruchom bezpośrednio gotowy plik wykonywalny **`LicznikKlikniec.exe`** lub kliknij dwukrotnie w **`run.bat`**.
- Do rekompilacji z kodu źródłowego (`Program.cs`) wystarczy uruchomić skrypt **`build.bat`** (wykorzystuje wbudowany w każdy system Windows kompilator `.NET Framework` – `csc.exe`, nie wymaga instalacji żadnych dodatkowych narzędzi!).

### 2. Wersja Przeglądarkowa (Alternatywna)
- Otwórz plik **`index.html`** w dowolnej przeglądarce internetowej (Chrome, Edge, Firefox).
